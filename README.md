J'ai opté pour GitHub Pages en tant que plateforme d'hébergement, du fait de sa gratuité, de sa facilité d'utilisation et de son adéquation pour accueillir des sites web statiques en HTML. Elle offre aussi une gestion aisée du code source et des actualisations du site.
